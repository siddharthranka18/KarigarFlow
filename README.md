# KarigarFlow

Gold Inventory & Karigar Management System.

## Overview

KarigarFlow helps jewellery businesses track gold issued to karigars,
record returned jewellery and scrap, calculate fine-gold balances,
and identify unusual wastage.

## Core Features

- Karigar management
- Gold issue and receipt tracking
- Fine-gold balance calculations
- Allowed vs actual wastage
- Loss alerts
- Daily gold stock statement
- AI-assisted scale reading with human confirmation

## Tech Stack

- Frontend: React + TypeScript
- Backend: FastAPI
- Database: PostgreSQL
- Testing: Pytest
